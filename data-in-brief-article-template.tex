\subsection*{Abstract}
This data article describes a curated benchmark resource for sequence- and structure-aware analysis of human G protein-coupled receptors (GPCRs). The collection contains 284 full-length human GPCR sequences organized into nine biologically defined classes or class-A subclasses, together with seven reduced 19-protein subsets (133 sequence instances) prepared for standardized structure-alignment workflows. Sequence records were retrieved programmatically from GPCRdb and are accompanied by transmembrane-topology annotations, GPCRdb reference alignments, and dataset-level metadata. Structure-associated data include AlphaFold Protein Structure Database models in PDB format, Predicted Aligned Error (PAE) matrices in JSON format, C$\alpha$ residue-distance matrices, residue-index maps, and PAE-derived confidence-weight matrices. The repository also stores precomputed multiple-sequence and multiple-structure alignment outputs, per-tool execution artifacts, consolidated baseline tables, and Python/shell scripts used for acquisition, transformation, metric preparation, and workflow execution. Data are organized by a consistent dataset naming scheme that links sequences, structures, derived matrices, reference alignments, and software outputs. The resource is intended for reproducible benchmarking of transmembrane-protein alignment methods, development of structure-aware scoring functions, independent reanalysis of GPCR residue correspondences, and construction of alternative benchmark protocols. The public GitHub repository and the exact source commit used for this article are reported in the Specifications Table.

\section*{VALUE OF THE DATA}
\begin{itemize}
    \item The dataset links full-length human GPCR sequences to topology annotations, AlphaFold structures, PAE information, residue-distance matrices, reference alignments and precomputed alignment outputs under a common identifier scheme. This reduces the data-integration work required to construct reproducible benchmarks for transmembrane-protein alignment.

    \item The nine full GPCR groups span class-A aminergic, peptide, protein and lipid-related subclasses as well as classes B1, B2, C, F and T2. The collection therefore provides groups with substantially different sequence counts and protein-length distributions, including long adhesion GPCRs, while retaining a common seven-transmembrane receptor context.

    \item The seven reduced 19-protein subsets can be reused when researchers need fixed-size structural benchmarks or when an alignment workflow has practical restrictions on the number or size of input structures. Because the selected protein identifiers are explicitly stored, these subsets can be reproduced without resampling.

    \item The raw AlphaFold PAE matrices, C$\alpha$ distance matrices, residue-index maps and PAE-derived weights can be reused independently of the alignment outputs. They support development or validation of alternative structure-aware objectives, confidence-aware scoring schemes, contact/distance analyses, and residue-correspondence metrics.

    \item The repository includes reference alignments, precomputed outputs from multiple sequence- and structure-based aligners, execution artifacts, and workflow scripts. Researchers can compare a new method with archived baselines, recompute derived quantities, audit the data-preparation steps, or substitute updated structures and aligners while preserving the same benchmark organization.
\end{itemize}

\section*{BACKGROUND}
G protein-coupled receptors (GPCRs) form a structurally related family of membrane receptors characterized by a conserved transmembrane helical architecture despite substantial sequence diversity. Structure-based analysis can therefore complement conventional sequence-only alignment when residue correspondence is difficult to infer from sequence identity alone \cite{cvicek2016gross}. GPCRdb provides curated receptor classifications, sequences and alignment resources \cite{pandyszekeres2023gpcrdb}, whereas AlphaFold and the AlphaFold Protein Structure Database provide broad access to predicted three-dimensional protein structures and confidence information \cite{jumper2021alphafold,varadi2024afdb}.

The present dataset was assembled to make the inputs, structural derivatives, reference alignments and software outputs used in a structure-aware GPCR alignment study directly reusable. It accompanies the related manuscript \cite{cedeno2026structalign} and extends the data resources used in the earlier topology-aware TMP-M2Align work \cite{cedeno2025tmpm2align}. This article documents the dataset itself, its provenance, file organization and generation procedures; it does not report comparative conclusions about alignment methods.

\subsection*{Structural and confidence-derived files}
For each available structure, \texttt{*\_D.csv} stores a square residue-by-residue C$\alpha$ Euclidean distance matrix. The associated \texttt{*\_idx.csv} file maps each matrix row/column to the residue sequence number read from the PDB file. The distance-generation script clips values above 50~\AA{} to 50~\AA{} in the stored matrix. PAE JSON files contain AlphaFold predicted aligned error values, and \texttt{*\_W.csv} files store the corresponding exponentially transformed confidence weights described below.

\subsection*{Reference and precomputed alignments}
Reference alignments are retained in \texttt{GPCRdb/reference\_alignments/} and are named using the same dataset identifiers as the sequence files. The \texttt{GPCRdb/precomputed/} directory stores method-specific FASTA alignments and baseline tables. Archived outputs include sequence-based and structure-based methods, such as ClustalW, Kalign, MAFFT, MUSCLE5, T-Coffee, TM-Aligner, Caretta, FoldMason, mTM-align, MUSTANG and US-align, depending on dataset availability. The presence of an archived output does not imply that it was included in every comparison in the related research article. The \texttt{status} and \texttt{message} fields in baseline tables should be consulted when reusing automated outputs.

\section*{EXPERIMENTAL DESIGN, MATERIALS AND METHODS}

\subsection*{1. Definition of GPCR groups and sequence acquisition}
The primary sequence collection was restricted to \textit{Homo sapiens}. The script \texttt{scripts/downloadsequences.py} queries the GPCRdb REST endpoint \url{https://gpcrdb.org/services/proteinfamily/proteins} using the class/subclass slugs \texttt{001\_001}, \texttt{001\_002}, \texttt{001\_003}, \texttt{001\_004}, \texttt{002}, \texttt{003}, \texttt{004}, \texttt{006}, and \texttt{009}. For every returned receptor, the script writes the GPCRdb entry name and amino-acid sequence in FASTA format and records the number of sequences and minimum/maximum sequence length in \texttt{dataset\_summary.csv}. GPCRdb nomenclature and receptor-family resources are described by P\'andy-Szekeres et al. \cite{pandyszekeres2023gpcrdb}.

The repository-level names \texttt{classA\_001} through \texttt{classT2} are used consistently for all subsequent data products. These names provide stable links among sequence, topology, structure, matrix, reference-alignment and software-output folders.

\subsection*{2. Construction of the reduced 19-protein subsets}
The reduced benchmark was generated as a deterministic subset rather than by repeated random sampling. The selected receptor names for the seven groups with at least 19 members are stored verbatim in \texttt{GPCRdb/List19Proteins.txt}. Corresponding sequence, structure, matrix and alignment folders use the suffix \texttt{\_19}. This representation was introduced to standardize input size for structure-alignment workflows and to support software with practical input-size constraints. The mTM-align family of algorithms is one of the structural-alignment methods represented in the archived benchmark outputs \cite{dong2018mtmalign}. Groups containing fewer than 19 proteins in the full collection (B1 and F) are used directly rather than duplicated under an artificial \texttt{\_19} label.

\subsection*{3. Transmembrane-topology annotations}
Per-residue topology annotations are stored in \texttt{GPCRdb/sequences/tmregions/} as \texttt{*\_predicted\_topologies.3line}. Each entry contains a FASTA-like identifier line, the full protein sequence, and a same-length topology string. In these files, \texttt{M} identifies membrane-spanning residues, whereas \texttt{I} and \texttt{O} encode residues on the two non-membrane sides of the topology. The topology-prediction workflow used DeepTMHMM, a deep-learning method for alpha- and beta-transmembrane protein topology prediction \cite{hallgren2022deeptmhmm}. Full and reduced topology files preserve the same receptor naming used in the FASTA collections.

\subsection*{4. AlphaFold structure and PAE acquisition}
Predicted structures and confidence data were acquired from the AlphaFold Protein Structure Database, which distributes AlphaFold predictions at proteome scale \cite{jumper2021alphafold,varadi2024afdb}. The acquisition script \texttt{scripts/download.py} maps each receptor to its UniProt accession and requests AlphaFold database model version~6 using the file patterns

\begin{verbatim}
AF-{UniProt_ID}-F1-model_v6.pdb
AF-{UniProt_ID}-F1-predicted_aligned_error_v6.json
\end{verbatim}

The PDB file is stored under \texttt{GPCRdb/alphafold\_pdb/} and the predicted-aligned-error JSON file under \texttt{GPCRdb/alphafold\_json/}. JSON records used in this dataset contain a \texttt{predicted\_aligned\_error} matrix. These PAE matrices are retained as raw confidence-associated data so that alternative weighting or filtering functions can be applied without regenerating structural predictions.

\subsection*{5. C$\alpha$ distance matrices and residue-index maps}
Structural distance files were generated with \texttt{scripts/distanceandindex.py}, which uses NumPy and Biopython's \texttt{Bio.PDB.PDBParser} \cite{cock2009biopython}. For each PDB file, the first model is read. Chain A is used when present; otherwise, the first available chain is selected. Hetero residues and residues lacking a C$\alpha$ atom are skipped. If $\mathbf{x}_i$ and $\mathbf{x}_j$ are the Cartesian C$\alpha$ coordinates of residues $i$ and $j$, the stored distance is

\begin{equation}
D_{ij}=\min\left(\lVert \mathbf{x}_i-\mathbf{x}_j \rVert_2, 50\,\text{\AA}\right).
\end{equation}

Matrices are written as decimal CSV files (\texttt{*\_D.csv}). A companion integer file (\texttt{*\_idx.csv}) stores the PDB residue number for each matrix row/column, allowing matrix indices to be reconciled with residue numbering even when a coordinate file contains missing or excluded records.

\subsection*{6. PAE-derived confidence weights}
The script \texttt{scripts/generar.py} reads the PAE array from each AlphaFold JSON record and transforms it into a confidence-weight matrix using

\begin{equation}
W_{ij}=\exp\left(-\frac{\mathrm{PAE}_{ij}}{\tau}\right), \qquad \tau=10.0.
\end{equation}

The generated matrices are stored as \texttt{*\_W.csv} in \texttt{GPCRdb/weights/}. The source PAE data are preserved separately, so users can recompute $W$ with a different $\tau$ or use the PAE values directly.

\subsection*{7. Reference alignments}
GPCRdb alignment services were used to retain family-specific reference residue correspondences. Reduced references were generated by \texttt{scripts/downloadmsareferences\_19.py}, which requests \url{https://gpcrdb.org/services/alignment/protein/{protein_list}/} for the explicit list of receptors in each 19-protein subset. Returned aligned sequences are written in FASTA format. The repository also contains MSF-compatible versions used by scoring utilities. Reference files are named after the corresponding dataset, enabling direct pairing with predicted alignments.

\subsection*{8. Precomputed alignment outputs and structural-alignment workflows}
The dataset retains alignment files generated during benchmark preparation so that users need not rerun every third-party tool before inspecting or extending the benchmark. Per-dataset FASTA files are located in \texttt{GPCRdb/precomputed/}; a global \texttt{baselines.csv} stores the fields \texttt{dataset}, \texttt{method}, \texttt{objective\_1}, \texttt{objective\_2}, \texttt{fasta}, \texttt{status}, and \texttt{message}. These tabular values are provided as machine-readable experiment records rather than as conclusions of this data article.

Structure-alignment outputs and logs are additionally grouped under \texttt{Tests/}. The repository provides dedicated workflows for Caretta \cite{akdel2020caretta}, MUSTANG \cite{konagurthu2006mustang}, mTM-align \cite{dong2018mtmalign}, FoldMason \cite{gilchrist2026foldmason}, and US-align \cite{zhang2022usalign}. Shell scripts in \texttt{scripts/} define the batch execution and data-preparation steps. FoldMason's use of local distance-difference information is related to the lDDT framework used broadly for superposition-free structural assessment \cite{mariani2013lddt}. Users should rely on the stored status/log information to identify successful, partial, or unavailable executions for a specific tool/dataset combination.

\subsection*{9. Reproducibility and provenance}
The acquisition and transformation pipeline is retained with the data. Key files include \texttt{downloadsequences.py}, \texttt{download.py}, \texttt{downloadmsareferences\_19.py}, \texttt{generar.py}, \texttt{distanceandindex.py}, conversion and metric-preparation scripts, and shell workflows for the structural aligners. The exact public repository state used to prepare this article is identified by commit \texttt{3e339cae97116fa04f98769b7324c3443334bc97}. This commit-level identifier allows future repository changes to be distinguished from the data snapshot described here. The repository README specifies CC BY 4.0 for the compiled/derived dataset while retaining the attribution and licensing conditions of the upstream data sources. The organization is intended to facilitate findability, accessibility, interoperability and reuse in line with FAIR data principles \cite{wilkinson2016fair}.

\section*{LIMITATIONS}
The dataset is a targeted benchmark rather than a complete census of all human GPCRs: it contains 284 receptors from the nine selected groups/subclasses used in the associated alignment study. The seven reduced 19-protein datasets are deterministic subsets of the full groups and must not be treated as independent biological samples. Structural files depend on the AlphaFold database model version used during acquisition; future database releases may change coordinates or confidence values. Predicted structures, especially for very long receptors such as adhesion GPCRs, can contain regions of heterogeneous confidence, and PAE-derived weights inherit this uncertainty as well as the fixed $\tau=10$ transformation used here. Precomputed aligner outputs are heterogeneous because third-party methods differ in accepted input sizes, formats and failure modes; absent or failed executions should not be interpreted as numerical zeroes, and the stored status/log fields should be checked. The GitHub commit provides an exact version identifier but is not a repository DOI.
